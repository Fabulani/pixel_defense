# HUD panel blocks building and selecting under it

- **Type:** bug / UX
- **Priority:** low
- **Area:** UI

The HUD panel (top right) eats clicks and taps where it overlaps the map, so a tower under it can't be built or selected. Options: set `mouse_filter = IGNORE` on the parts that don't need input, shrink the panel, or let the camera fit leave a margin for it.
